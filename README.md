# Nethaji & Gayathri Wedding Website

Complete editable static website, matching the Vercel deployment.

## Run locally
Open a terminal in this folder and run:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Edit
- index.html: page content and photo placement
- style.css: layout, colours and animations
- app.js: interactions and motion
- assets/: photos, artwork, fonts and invitation video

## Deploy
Upload this folder to a static web host or deploy with Vercel. No build step or dependencies required. Vercel configuration is included.

Live website: https://nethaji-gayathri-wedding.vercel.app
